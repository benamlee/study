  1. 第三个选项
  2. 第四个选项
  3. 第五个选项

倒序排列（reversed）：

  1. 第三名：铜牌
  2. 第二名：银牌
  3. 第一名：金牌

1.4 定义列表 <dl>

HTML
超文本标记语言，用于创建网页的结构。
CSS
层叠样式表，用于控制网页的样式和布局。
JavaScript
一种脚本语言，用于为网页添加交互功能。
