⚠️ 学习提示：
  • 本课中的图片、视频、音频都来自网络，需要联网才能显示
  • 你可以把 src 换成自己电脑上的文件路径（如 images/myphoto.jpg）
  • 视频和音频文件较大，建议使用自己的小文件测试
  • alt 属性不是可选的——它对无障碍访问和 SEO 非常重要
  • 所有媒体标签都可以配合 CSS 进行样式美化

✏️ 课后练习

  1. 找一张你喜欢的图片 URL，用 <img> 显示在页面上
  2. 给你的图片添加 alt、title、width 属性
  3. 用 <figure> 和 <figcaption> 包裹一张图片并添加说明
  4. 创建一个带 controls 和 loop 的视频播放器
  5. 用 <iframe> 嵌入你喜欢的网站
