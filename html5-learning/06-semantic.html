什么是语义化标签？

语义化标签就是用 有含义的标签 来描述内容，而不是一律使用 <div>。

为什么要使用语义化标签？

  • SEO 优化 — 搜索引擎（如 Google）根据语义化标签理解页面结构，提高排名
  • 无障碍访问 — 屏幕阅读器能通过 <nav>、<main> 等标签快速导航
  • 代码可读性 — 团队合作时，看到 <header> 就知道是头部，<footer> 是底部
  • 标准化 — 符合 W3C 标准，未来浏览器更新也能兼容
  • 自动功能 — 有些浏览器提供"阅读模式"，会根据语义化标签提取正文

HTML5 常用语义化标签一览

标签 含义 使用场景
<header> 页眉 / 头部 页面顶部，含 Logo、标题、搜索框
<nav> 导航 主导航菜单、页脚导航
<main> 主要内容 页面的核心内容，一页只有一个
<section> 章节 按主题分组的内容区块
<article> 独立文章 博客文章、新闻、用户评论
<aside> 侧边栏 / 旁注 广告、推荐文章、相关链接
<footer> 页脚 版权信息、联系方式、备案号
<figure> 插图 / 媒体容器 图片、图表、代码块等独立内容
<figcaption> 插图标题 配合 <figure> 使用
<time> 时间 / 日期 发布时间、活动时间
<mark> 高亮标记 搜索关键词高亮、重点内容
<details> / <summary> 可折叠详情 FAQ、展开/收起内容

使用建议

✅ 推荐这样用

  • 用 <header> 放页面/区块的标题和介绍
  • 用 <nav> 放主要导航链接
  • 用 <main> 放页面的唯一核心内容
  • 用 <section> 对内容按主题分组
  • 用 <article> 放独立完整的文章/内容
  • 用 <aside> 放辅助/补充内容
  • 用 <footer> 放版权/联系方式

❌ 避免这样用

  • 不要为了"语义化"而滥用语义化标签，<div> 仍然有用
  • 不要在 <nav> 中放每个链接（如文章内的链接不属于导航）
  • 不要在一个页面中使用多个 <main>
  • 不要把 <section> 当 <div> 用——它应该有主题和标题
  • 不要为了样式方便而牺牲语义
