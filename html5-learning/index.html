🚀 HTML5 入门学习教程

欢迎来到 HTML5 学习之旅！本教程从零开始，带你一步步掌握 HTML5 的核心知识。

📚 学习目录

点击下面的链接开始学习：

  • 第 1 课：HTML5 文档结构与基础标签
    DOCTYPE html head body h1-h6 p 学习 HTML 文件的基本结构、标题、段落、注释等最基础的元素
  • 第 2 课：列表与链接
    ul ol li a nav 学习无序列表、有序列表、超链接、页面内跳转
  • 第 3 课：图片、视频与音频
    img figure video audio 学习在页面中嵌入图片、视频和音频文件
  • 第 4 课：表格
    table tr td th thead tbody 学习创建和美化表格数据
  • 第 5 课：表单与输入
    form input button select textarea label 学习各种表单控件，收集用户输入的数据
  • 第 6 课：HTML5 语义化标签
    header nav main section article aside footer 学习使用有意义的标签构建页面结构，提升可读性和 SEO
  • 🎯 综合练习：个人主页
    运用前面学到的所有知识，动手制作一个完整的个人简介页面

💡 学习建议

  1. 按顺序从第 1 课开始学习
  2. 每学完一课，在浏览器中打开该文件查看效果
  3. 尝试修改代码中的内容，观察变化
  4. 完成第 7 课的综合练习，巩固所学知识
  5. 建议同时打开 浏览器开发者工具（F12）查看 HTML 结构

提示：本教程所有文件可以直接用浏览器打开查看效果，无需安装任何软件。
